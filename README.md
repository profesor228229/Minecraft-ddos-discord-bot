# Parkour Bot — клиент-сайд Fabric мод для Minecraft 1.16.5

Клиентский мод для Minecraft 1.16.5 на Fabric, который автоматически идёт к указанной
точке: ходит, прыгает на 1 блок вверх, спрыгивает с уступов до 3 блоков и перепрыгивает
1-блочные дыры (паркур). Цель указывается либо ПКМ по блоку, либо координатами через чат.
Отдельный freecam на `V` позволяет удобно облетать карту и кликать по блоку, куда нужно
идти.

> ⚠️ Это **клиент-сайд** мод. Он управляет вашим персонажем, нажимая клавиши за вас, и
> работает как на сингл-игре, так и на серверах (анти-чит может счесть это нечестной
> игрой — используйте на свой страх и риск, как и Baritone).

## Установка

1. Поставьте [Fabric Loader](https://fabricmc.net/use/installer/) на Minecraft 1.16.5.
2. Положите в `.minecraft/mods/` следующее:
   - [Fabric API 0.42.0+1.16](https://modrinth.com/mod/fabric-api/version/0.42.0+1.16)
   - `parkourbot-0.1.0.jar` (этот мод)
3. Запустите Minecraft через профиль `fabric-loader-1.16.5`.

## Управление

| Действие | Клавиша / команда |
| --- | --- |
| Выделить цель по прицелу (стоит на блок выше) | **G** |
| Запустить / остановить бота (нужна цель) | **B** |
| Полностью остановить бота и сбросить цель | **N** |
| Включить / выключить freecam | **V** |
| В freecam: ПКМ по блоку — поставить цель | (правая кнопка мыши) |
| Команда: идти к координатам | `/gotoxyz <x> <y> <z>` |
| Команда: остановить бота | `/parkourstop` |

Все клавиши настраиваются в `Options → Controls → Parkour Bot`.

### Freecam

- `V` включает/выключает freecam.
- Игрок остаётся на месте; камера летает: **WASD** — движение, **Space** — вверх,
  **Left Ctrl** (Sneak) — вниз, **Left Shift** (Sprint) — ускорение в 3 раза.
- Мышь крутит камеру, не персонажа.
- **ПКМ** по блоку в freecam-режиме сразу ставит цель боту.

### Типичный флоу

1. Нажмите `V` — открылся freecam.
2. Долетите до места, куда хотите попасть, наведитесь на нужный блок.
3. Нажмите ПКМ — цель установлена (вы увидите её координаты в чате).
4. Нажмите `V` ещё раз, чтобы вернуться в персонажа.
5. Нажмите `B` — бот побежит, прыгая по пути.
6. Если что-то пошло не так — `N`.

## Что бот умеет

- 4 направления + 4 диагонали ходьбы.
- Прыжок на 1 блок вверх.
- Спрыгивание с 1–3 блоков вниз.
- Паркур через 1-блочную дыру (с разбегу спринтом).
- Heuristic A* пасфайндинг до 256 блоков от старта, до 20 000 итераций (≈ 1–2 секунды).
- Автоматическое обнаружение «застрял» (3 секунды без движения) и репланирование.

## Чего бот **не** умеет

Это **не** Baritone. Сделано за один заход и **не** учит: разрушение/постановку блоков,
плавание, лестницы, лианы, лодки, длинный паркур (2-блочные дыры с разбегу), хитрые
sprint-jump'ы по диагонали, защиту от мобов. Если задание сложнее — Baritone до сих пор
лучший выбор.

## Сборка из исходников

```bash
./gradlew build
```

Готовый jar — `build/libs/parkourbot-0.1.0.jar`.

Требуется JDK 17 для запуска Gradle / Loom; компилируется в Java 8 байткод (как требует
Minecraft 1.16.5).
